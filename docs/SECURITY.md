# Security audit (2026-10-08)

Scope: whole repository at Phase 6. "Checked by" names the executable test; items without one are review findings.

| Area | Finding | Status | Checked by |
|---|---|---|---|
| SQL injection | Every statement is a constant or built from reviewed fragments (`_COLS`, an allow-listed ORDER BY, `?` placeholder runs); all values are bound. Hostile ids/labels/aliases stay inert data | OK | `test_security.py::test_sql_*`, `test_answer.py::test_sql_values_are_bound_not_interpolated`, `test_query_unit.py::test_hostile_llm_output_is_inert_data` |
| Prompt injection | The LLM yields strictly validated data; no tool use; only verified values reach the context; user text travels only in the `user` role; 3 real injection prompts leave the DB untouched | OK (residual: the model can *misread* a question, e.g. pick a wrong camera; that is visible in `provenance`, not an execution risk) | `test_query_real.py::test_real_prompt_injection_cannot_cause_actions` |
| LLM tool execution | None exists. `godseye/query` and `godseye/answer` contain no subprocess/eval/exec/file-write primitives | OK | `test_query_unit.py::test_query_package_has_no_execution_primitives`, `test_answer.py::test_config_validation_and_no_execution_primitives`, `test_security.py::test_no_dangerous_calls...` |
| Filesystem traversal | camera ids are `[A-Za-z0-9_.-]{1,64}` everywhere; clips are addressed by integer id from SQLite and the resolved path must stay inside `clips/` (symlink and poisoned-DB-path cases tested); web media never accepts a path | OK | `test_web.py::test_media_cannot_escape_the_clips_directory`, `test_storage.py::test_unsafe_camera_id_*`, `test_security.py::test_camera_ids_are_path_safe_everywhere` |
| Credentials | **Found:** GStreamer error text echoed `rtsp://user:password@host` into logs and `CameraStats.last_error` (visible through `health()`). **Fixed:** `redact_text` on every error/log sink; unexpected-exception tracebacks only at DEBUG. No secrets in the tree. Camera URLs use `${ENV}` expansion | Fixed | `test_security.py::test_gstreamer_errors_do_not_leak_camera_passwords`, `test_no_secrets_in_the_tree` |
| API security (web) | Loopback bind only (refuses other hosts), per-install 256-bit token (file mode 0600) as HttpOnly SameSite=Strict cookie or Bearer, constant-time compare, Host check (DNS rebinding), `X-Requested-With` + Origin check (CSRF), body <= 8 KB, 30 questions/min, strict CSP (no inline script), nosniff, no stack traces, no URL/body logging, Range handling validated | OK for a single-user local tool. **Not provided:** TLS, per-user accounts, per-client rate limits, audit log | `test_web.py` (11 tests) |
| Media access | Every `/media` and `/api/frame` request needs the token; status must be `complete`; size must match the recorded size (else 410) | OK | `test_web.py::test_damaged_missing_and_marked_clips_are_refused` |
| PII | Clips and tracks show people. Privacy masks (blur/black) can be applied to the original before it is stored; the store **refuses** to persist an unmasked original when masks are configured but not applied. **Gaps:** no encryption at rest; DB/knowledge files use the default umask; Re-ID gallery vectors and track embeddings are biometric-like data with no per-identity deletion API; only clip retention exists (`EvidenceStore.purge_clips`, manual, not scheduled); question text is sent to the peer LLM | Open (documented) | `test_storage.py::test_unsafe_camera_id_and_unmasked_original_refused`, `test_purge_clips_*` |
| Supply chain | `torch.load(weights_only=False)` is used for the two pinned FastReID checkpoints (pickle): a replaced weights file would execute code. Checksums of the weights are not verified. Third-party sources are cloned at pinned commits (documented, not hash-verified at runtime); Python packages are frozen in `requirements*.lock` without hashes | Open (recommend pinning sha256 of `models/fastreid/*.pth`) | `test_security.py::test_torch_load_is_limited_to_the_pinned_checkpoint_loader` |
| Remote LLM (Ray) | Gateway on loopback exposing 3 routes; remote actor is stdlib-only, whitelists fields/models/options/size. **The Ray cluster has no authentication** (6379/10001/8265 reachable on the LAN means remote code execution on every node) | Cluster-level risk, not ours; see `docs/CLUSTER.md` | `test_cluster.py` |
| Knowledge store | Users can teach aliases; a wrong alias redirects future questions (intended). No access control beyond the local process boundary | Accepted | |
| DoS | `ThreadingHTTPServer` has no thread cap; the rate limit is global, not per client; frame decoding endpoints cost CPU. Acceptable on loopback | Accepted | |
| Dependencies | `python-dotenv` was satisfied from the user's site-packages, so the venv was not self-contained and `python -I` runs failed. Installed into the venv and all packages frozen | Fixed | `tests/test_storage.py::test_write_failures_from_the_os_*` (runs `python -I`) |
